# Capsule Architecture Comparison Interpretation

The capsule architecture comparison was carried out to evaluate how different anomaly detection architectures affected image-level anomaly detection performance. This experiment was added in response to supervision feedback requesting a clearer explanation of the model architecture used for detection and a comparison with alternative configurations.

The comparison included three PatchCore configurations and two PaDiM configurations. PatchCore was evaluated using `resnet18`, `resnet50` and `wide_resnet50_2` backbones. PaDiM was evaluated using `resnet18` and `resnet50`, with `n_features` set to 100 for the ResNet50 configuration because the installed Anomalib implementation requires the number of retained features to be specified for that backbone.

The results show that PatchCore achieved stronger image-level performance than PaDiM across the tested capsule configurations. PatchCore with `resnet50` produced the highest image AUROC and image F1-score, with an AUROC of 0.9936 and an F1-score of 0.9818. PatchCore with `wide_resnet50_2` also performed strongly, achieving an AUROC of 0.9932 and an F1-score of 0.9770. The PatchCore `resnet18` configuration was slightly lower but still strong, with an AUROC of 0.9817 and an F1-score of 0.9767.

PaDiM produced lower image-level scores in this comparison. The PaDiM `resnet18` configuration achieved an AUROC of 0.8975 and an F1-score of 0.9463, while the PaDiM `resnet50` configuration with 100 retained features achieved an AUROC of 0.9110 and an F1-score of 0.9469. Although PaDiM remained viable, the PatchCore configurations provided a stronger balance of image-level anomaly detection performance for the capsule category.

These findings support the use of PatchCore as the preferred architecture for the main detection branch of the risk-aware inspection pipeline. However, the result should not be interpreted as model superiority in every possible context. The wider dissertation results show that localisation quality, semantic interpretation, review workload and operational decision support must also be considered. Therefore, the selected architecture is best described as providing the strongest overall image-level detection performance in this comparison, while the wider pipeline evaluation remains necessary for judging operational suitability.

The comparison is useful for the dissertation because it demonstrates that the model architecture was not selected arbitrarily. Instead, alternative configurations were tested under a consistent experimental setup, and the results provide evidence that PatchCore, particularly with the `resnet50` backbone in this capsule experiment, provides a strong basis for the proposed risk-aware visual inspection framework.
